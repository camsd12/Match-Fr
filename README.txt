MATCH FR PWA — DÉMARRAGE RAPIDE

1. Décompressez MatchFR-PWA.zip sur votre PC.
2. Le dossier contient l'application complète (HTML/CSS/JS/PWA).
3. Pour la publier gratuitement, créez un compte GitHub puis un dépôt PUBLIC nommé match-fr.
4. Dans le dépôt : Add file > Upload files, glissez TOUS les fichiers ET dossiers du dossier MatchFR-PWA, puis validez avec Commit changes.
5. Settings > Pages > Build and deployment > Source: Deploy from a branch > Branch: main > /(root) > Save.
6. Attendez la publication. GitHub affichera l'adresse HTTPS du site dans Settings > Pages.
7. Sur l'iPhone, ouvrez cette adresse dans Safari > Partager > Sur l'écran d'accueil > activez « Ouvrir comme app web » > Ajouter.

IMPORTANT : matches.json contient actuellement des données de démonstration. L'app relit ce fichier au démarrage, au rafraîchissement et toutes les 5 minutes quand elle est ouverte. Pour de vraies données automatiquement actualisées sans intervention, il faudra connecter une API sportive et une source fiable/licenciée pour les diffuseurs français. L'hébergement de la PWA peut rester gratuit ; les données sportives/TV en temps réel ne sont pas garanties gratuites.
